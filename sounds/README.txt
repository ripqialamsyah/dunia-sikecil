Folder Audio Rekaman Asli (Opsional)
=======================================

Secara default, game "Dunia Kecil" sudah memiliki suara hewan, kendaraan,
buah, dan pengucapan kata otomatis tanpa file tambahan.

Jika ingin memakai rekaman suara ASLI (misalnya suara kucing/sapi/kereta nyata
dari file .mp3/.ogg/.wav bebas royalti, atau rekaman suara orang tua):

1. Letakkan file audio di folder `sounds/` ini dengan nama sesuai ID berikut:
   - Hewan:
     cat.mp3, dog.mp3, cow.mp3, duck.mp3, frog.mp3, elephant.mp3, lion.mp3, sheep.mp3
   - Kendaraan:
     car.mp3, train.mp3, airplane.mp3, ship.mp3, bus.mp3, bicycle.mp3
   - Makanan/Efek:
     crunch.mp3, gulp.mp3, juicy.mp3

2. Daftarkan nama file yang Anda tambahkan ke dalam `sounds/list.json`, contoh:
   ["cat.mp3", "dog.mp3", "cow.mp3"]

3. Game akan otomatis memutar rekaman asli tersebut saat karakter diklik!
